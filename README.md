# Rentora Home Page Starter

## Run locally
1. Open this folder in Visual Studio Code.
2. Install/use the Live Server extension.
3. Right-click `index.html` and select **Open with Live Server**.

The shared navbar and footer are loaded with `fetch()`, so do not open the HTML file directly as `file://`.

## Included
- Responsive Rentora homepage
- Shared navbar and footer components
- Profile dropdown
- Persistent light/dark theme toggle
- Persistent LTR/RTL direction toggle
- Home page CSS and global design tokens

## Notes
The Login, Register, dashboard, and secondary public-page links are starter links for the next build phase. Dashboard preview values are illustrative. Replace the placeholder contact email and stock images before production.
